# Islamic Civil Calendar

Islamic civil chronology and provider formatting remain separate from neutral mechanisms. Common 1.19.80 (dc4aac326964ca4400b6e21851d16eea674040c8) supplies arithmetic, Gregorian/JDN coordinate helpers, resource metadata and ABI. Native .so uses the actual Common static archive from a pinned submodule; older local Common code copies are deleted. Tests and offline native source package are preserved.
