# Islamic Civil Calendar

Islamic civil chronology and provider formatting remain separate from neutral mechanisms. Common 1.19.81 (a99ef676b0e43c7e645c81756e3fd38be0a54406) supplies arithmetic, Gregorian/JDN coordinate helpers, resource metadata and ABI. Native .so uses the actual Common static archive from a pinned submodule; older local Common code copies are deleted. Tests and offline native source package are preserved.
